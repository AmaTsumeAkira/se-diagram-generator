七、复验方式

1. npm run build ✅ 通过（tsc -b 无错误）
2. npm run lint ✅ 72 problems（修复前 80，净减 8；新增文件 configSerialize.ts 仅保留 2 处与既有代码风格一致的 any）
3. 界面复验：应用里点一次工具栏的「重置」（会清掉 localStorage 里那份缺坐标的旧数据并重新装载内置示例）， 总体 ER 图即显示上面的设计布局；之后刷新页面布局不会再变。
